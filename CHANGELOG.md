# Changelog — Aroli Desktop Beta

Aroli Desktop is in public beta. Versions use `0.1.0-beta.N` until the first
stable release. This file records the beta line only.

## [Unreleased]

### Changed

- Reset release numbering to `0.1.0-beta.1`; GitHub releases are pre-releases,
  and desktop and CLI update checks follow beta tags.
- Removed the local remote for the previous repository, fork migration tooling,
  Umbra rename migration code, and product compatibility aliases.

### Removed

- Removed the stable promotion workflow and the retired 1.x–3.x changelog.

## [0.1.0-beta.1] - 2026-09-28

### Added

- First release in the Aroli Desktop beta line, with the current Hyprland,
  Quickshell, lock screen, settings, and personalization experience.
- Guided installation, diagnostics, snapshots, recovery, wallpaper palettes,
  and opt-in package profiles.

### Changed

- Release numbering and update flow use beta pre-releases until the project is
  ready to declare a stable 1.0.0.

### Removed

- Previous repository migration and compatibility paths.
